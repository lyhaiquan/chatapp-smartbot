# Tổng hợp vai trò & chức năng nghiệp vụ các file dự án Smart AI Chat

---

## Backend (Node.js/Express)

### 1. index.js
- **Vai trò:** File khởi động server Express, cấu hình các middleware, route API, socket.io, và các static file (uploads).
- **Chức năng:**
  - Khởi tạo server, socket.io
  - Đăng ký các route: auth, user, room, upload, friend, user-actions, admin
  - Health check, cung cấp ICE server cho WebRTC

### 2. socket/index.js
- **Vai trò:** Khởi tạo socket.io, xác thực kết nối, đăng ký các handler cho từng chức năng realtime.
- **Chức năng:**
  - Xác thực user qua middleware
  - Đăng ký handler: chat, message, webrtc (call), ai, friend
  - Cập nhật trạng thái online/offline

### 3. socket/ai.handler.js
- **Vai trò:** Xử lý các sự kiện AI Bot (bật/tắt, chat, dịch, tóm tắt, phân tích ảnh, ghi âm cuộc gọi).
- **Chức năng:**
  - Bật/tắt AI Bot cho từng user trong room
  - Gửi/nhận tin nhắn AI, dịch, tóm tắt, phân tích ảnh, ghi âm

### 4. socket/webrtc.handler.js
- **Vai trò:** Xử lý logic cuộc gọi video/audio, signaling WebRTC, quản lý trạng thái call.
- **Chức năng:**
  - Quản lý cuộc gọi (initiate, accept, reject, end, cancel)
  - Signaling WebRTC (offer, answer, ice-candidate)
  - Thông báo trạng thái chia sẻ màn hình

### 5. services/ai.service.js
- **Vai trò:** Tích hợp AI Gemini, dịch, tóm tắt, rate limit, cache dịch.
- **Chức năng:**
  - Gọi API Gemini AI, dịch, tóm tắt, phân tích ảnh, ghi âm
  - Quản lý cache dịch, rate limit

### 6. models/User.js, Room.js
- **Vai trò:** Định nghĩa schema User, Room cho MongoDB.
- **Chức năng:**
  - User: thông tin cá nhân, xác thực, ngôn ngữ, trạng thái
  - Room: thông tin nhóm, thành viên, quyền, AI bot

### 7. controllers/auth.controller.js
- **Vai trò:** Xử lý đăng ký, đăng nhập, xác thực OTP, quản lý user.
- **Chức năng:**
  - Đăng ký, gửi OTP, xác thực, đăng nhập, đổi mật khẩu

## Frontend (React/Vite)

### 1. src/App.jsx
- **Vai trò:** Root component, bọc các provider, render overlay cuộc gọi toàn cục.
- **Chức năng:**
  - Bọc ErrorBoundary, SocketProvider, CallProvider
  - Render CallModal, IncomingCallModal, NotificationPermission

### 2. src/routes/AppRoutes.jsx
- **Vai trò:** Định nghĩa các route, lazy load page, bảo vệ route (auth).
- **Chức năng:**
  - PrivateRoute/PublicRoute, loading fallback, route table

### 3. src/contexts/AuthContext.jsx
- **Vai trò:** Quản lý trạng thái xác thực, user, token, login/logout/register.
- **Chức năng:**
  - Lưu user/token vào localStorage, verify token, login/register/logout

### 4. src/contexts/SocketContext.jsx
- **Vai trò:** Quản lý kết nối socket.io, trạng thái online, đăng ký listener.
- **Chức năng:**
  - Kết nối/ngắt socket, quản lý onlineUsers, on/off event

### 5. src/hooks/useChat.js
- **Vai trò:** Hook quản lý tin nhắn, load, gửi, nhận, realtime, typing.
- **Chức năng:**
  - Load message, socket listener, gửi/nhận message, typing

### 6. src/components/chat/ChatWindow.jsx
- **Vai trò:** Giao diện cửa sổ chat chính, hiển thị message, input, AI toggle.
- **Chức năng:**
  - Hiển thị message, input, gọi điện, toggle AI, block user, load room info

### 7. src/components/chat/MiniAIChatBox.jsx
- **Vai trò:** Chatbox AI mini, chat với AI, dịch, tóm tắt, ghi âm, phân tích ảnh.
- **Chức năng:**
  - Gửi/nhận message AI, dịch, tóm tắt, ghi âm, phân tích ảnh, auto translate

# (Các file khác: routes, middlewares, models, services, utils...)
- **routes/**: Định nghĩa các API endpoint cho backend
- **middlewares/**: Xử lý xác thực, lỗi, upload file, CORS
- **models/**: Định nghĩa schema cho MongoDB
- **services/**: Tích hợp AI, dịch, gửi mail, lưu log
- **utils/**: Hàm tiện ích chung (helpers, logger...)
