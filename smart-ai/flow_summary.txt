# Flow Xử Lý Nghiệp Vụ: Tin nhắn, Cuộc gọi, Gửi file (Smart AI Chat)

---

## 1. Flow Tin Nhắn (Chat)

### Frontend:
1. **User nhập tin nhắn** tại `ChatWindow.jsx` → gọi hàm gửi message.
2. Gọi API gửi message (`roomAPI.sendMessage`) hoặc emit socket event `message:send` qua hook `useChat.js`.
3. **Socket event** gửi tới backend qua `SocketContext.jsx`.

### Backend:
4. **socket/message.handler.js** nhận event `message:send` → lưu vào MongoDB qua model `Message.js`.
5. Gửi lại message mới tới các client cùng room qua socket event `message:new`.

### Frontend:
6. **useChat.js** lắng nghe event `message:new` → cập nhật UI tại `ChatWindow.jsx`.

---

## 2. Flow Cuộc Gọi (Video/Audio Call)

### Frontend:
1. **User bấm gọi** tại `ChatWindow.jsx` → gọi `initiateCall` từ hook `useCall.js`.
2. `useCall.js` emit socket event `call:initiate` qua `SocketContext.jsx`.

### Backend:
3. **socket/webrtc.handler.js** nhận event `call:initiate` → kiểm tra trạng thái, lưu vào `activeCalls`, gửi event `call:incoming` tới user bị gọi.

### Frontend:
4. **CallModal.jsx** lắng nghe event `call:incoming` → hiển thị popup nhận cuộc gọi.
5. Khi user nhận cuộc gọi, emit `call:accept` → backend xác nhận, gửi event `call:accepted` lại cho caller.
6. Hai phía thực hiện signaling WebRTC qua các event: `webrtc:offer`, `webrtc:answer`, `webrtc:ice-candidate` (qua `webrtc.handler.js`).
7. Khi kết nối thành công, stream media (audio/video) được truyền trực tiếp P2P.
8. Kết thúc cuộc gọi: emit `call:end` → backend gửi event `call:ended` cho peer còn lại.

---

## 3. Flow Gửi File (Upload/Send File)

### Frontend:
1. **User chọn file** tại UI (ví dụ: `MessageInput.jsx` hoặc `UploadModal.jsx`).
2. Gọi API upload file (`uploadAPI.uploadFile`) hoặc emit socket event nếu là file nhỏ.

### Backend:
3. **routes/upload.routes.js** nhận request POST `/api/upload` → xử lý lưu file qua middleware `multer.js`.
4. Lưu thông tin file vào MongoDB (nếu cần), trả về URL file cho client.

### Frontend:
5. Nhận URL file, gửi message chứa link file qua API hoặc socket như flow tin nhắn.
6. **ChatWindow.jsx** hiển thị message có file đính kèm (hình ảnh, file, v.v.).

---

# Tóm tắt file chính trong từng flow

- **Tin nhắn:**
  - Frontend: `ChatWindow.jsx` → `useChat.js` → `SocketContext.jsx`
  - Backend: `socket/message.handler.js` → `models/Message.js`

- **Cuộc gọi:**
  - Frontend: `ChatWindow.jsx` → `useCall.js` → `CallModal.jsx` → `SocketContext.jsx`
  - Backend: `socket/webrtc.handler.js` → `models/Room.js`

- **Gửi file:**
  - Frontend: `MessageInput.jsx`/`UploadModal.jsx` → `uploadAPI` → `SocketContext.jsx`
  - Backend: `routes/upload.routes.js` → `middlewares/multer.js`

---

# Lưu ý
- Các flow đều có thể liên quan đến các file context/provider (AuthContext, SocketContext, CallContext) để quản lý trạng thái toàn cục.
- Các event realtime đều đi qua socket.io (socket handler backend, hook context frontend).
- Gửi file lớn sẽ dùng API REST, file nhỏ có thể gửi qua socket nếu cần realtime.
